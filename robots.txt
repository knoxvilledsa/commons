# The chapter site, live on the production domain. It is meant to be FOUND: in
# regular search and in AI search, so someone looking for the chapter through
# Google or through ChatGPT lands here. The preview `noindex` that kept this out
# of every index while it lived on new.knoxvilledsa.org is gone from _headers.
#
# Being findable and refusing to be training data are separate questions, and
# the chapter answers them differently. Crawling for SEARCH is allowed below.
# Crawling for MODEL TRAINING is refused, both by the Content-Signal line and by
# naming the training crawlers individually, because not all of them read the
# signal.
#
# Note the absence of a blanket `Disallow: /`. It would be the wrong tool even
# if we wanted to hide: a page has to be crawlable for a noindex header on it to
# be read and honored, so disallowing everything hides the instruction instead
# of the page.

Content-Signal: ai-train=no
