# knoxvilledsa.org

The public website of the **Knoxville Area chapter of the Democratic Socialists of America**, live at [knoxvilledsa.org](https://knoxvilledsa.org).

This repository holds the site as it is deployed: prebuilt static HTML generated by [Astro](https://astro.build), plus a handful of [Cloudflare Pages Functions](https://developers.cloudflare.com/pages/functions/) for the contact form, the email lists, and short links. There is no build step here. Cloudflare Pages serves the repository root as-is.

> [!IMPORTANT]
> **This is a publish target, not the source.** The site is built from the chapter's private source repository and published here by an automated step (`build.json` records when). Pages, newsletter issues, generated email templates and the CSS bundle are all build output, so editing them here will be overwritten by the next publish. To report a mistake or suggest a change, open an issue or email [contact@knoxvilledsa.org](mailto:contact@knoxvilledsa.org).

## Server-side endpoints

Everything under `functions/` is deployed by Cloudflare Pages alongside the static files. Each endpoint is **inert until its secrets and bindings are configured**: it answers `503 not_configured` (or, for short links, redirects home) rather than half-working.

| Route | Method | What it does |
| --- | --- | --- |
| `/api/contact` | `POST` | Contact form. Honeypot, Cloudflare Turnstile and a per-IP KV throttle, then an email to the chapter via [Resend](https://resend.com). Grievance reports route only to the Harassment Grievance Officer and never trigger an acknowledgement email. |
| `/api/subscribe` | `POST` | Starts a double opt-in signup. Sends one signed confirmation link and writes no subscription state, so submitting someone else's address can cost them one email but cannot change what they receive. |
| `/api/confirm` | `GET` | Verifies the HMAC-signed, single-use confirm token and opts the address in. |
| `/api/unsubscribe` | `GET`, `POST` | `POST` is the [RFC 8058](https://www.rfc-editor.org/rfc/rfc8058) one-click unsubscribe used by mail clients. `GET` only shows a confirmation button, so link-scanning mail filters cannot unsubscribe anyone. |
| `/go/<slug>` | `GET` | Redirects a short link (for flyers and slides) to a URL stored in the `LINKS` KV namespace. Unknown slugs go to the homepage. |

The required environment variables, KV bindings, Resend topic setup, and the reasoning behind each security decision are documented in [`functions/README.md`](functions/README.md) and in the header comment of each file. Read those before changing any endpoint. The token format in `functions/api/_subscribe_token.js` is a contract shared with the chapter's Python mail senders, and the `_*_theme.js` email templates are generated files.

## Hosting

The site runs on Cloudflare Pages. The platform files at the root do the following:

- **`_headers`** sets a strict Content Security Policy (same-origin only, except Cloudflare Turnstile on the two forms), `X-Frame-Options: DENY`, `nosniff`, and immutable caching for the fingerprinted `_astro/` bundle and the fonts.
- **`_redirects`** maps every URL from the chapter's former WordPress site (read from its sitemap) to its equivalent here, including old links to the governing PDFs, so bookmarks, search results and printed material keep working.
- **`robots.txt`** allows search indexing and declares `Content-Signal: ai-train=no`, and also names the major AI training crawlers individually, since not all of them honor the signal.

Privacy: there are no analytics, trackers, or third-party fonts. All typefaces are self-hosted so a visitor's IP address never reaches Google Fonts. The only third-party request is Cloudflare Turnstile, and it loads only on the contact and subscribe pages.

## Previewing locally

Cloudflare's own dev server reproduces production routing, `_headers`, `_redirects` and the Functions:

```sh
npx wrangler pages dev .
```

Then open <http://localhost:8788>. Without secrets and bindings the forms will answer `not_configured` and `/go/*` links will redirect home, which is the expected inert state. Wrangler writes a `.wrangler/` cache directory into the repo; delete it when you are done rather than committing it.

A plain static server (`python3 -m http.server`) will render pages but will not resolve extensionless URLs like `/about`, apply redirects, or run Functions.
